# Dashboard Visual Evolution

## Purpose

This document explains how the dashboard visuals evolved from earlier asset-specific prototypes into the current public SETA dashboard format.

The goal is not to show every historical design. The goal is to demonstrate iteration, product thinking, and a clear movement from exploratory dashboards toward a polished public-facing analytics surface.

## Current public dashboard

The current public dashboard screenshot is the primary visual for this portfolio repo:

```text
screenshots/dashboard_overview_public.png
```

This view is the strongest recruiter-facing visual because it shows a complete product surface:

- asset controls

## Earlier Tableau-style prototypes

Earlier AAPL, NVDA, and TSLA screenshots can be useful if added later, but they should be framed as prototypes or visual-evolution examples rather than as the current product surface.

Recommended use:

- show dashboard iteration over time
- demonstrate asset-specific visual experimentation
- support a case-study narrative

Not recommended:

- using older prototype screenshots as the primary README hero
- presenting all screenshots equally without context
